# 🎓 Zoho School of Technology Management System

A desktop-based **School Management System** developed using **Python and Tkinter GUI** to efficiently manage student and administrative operations in an educational institution.

This project was built to simplify educational management by providing an easy-to-use interface for handling student records, management tasks, and institution-related operations.

## 🚀 Overview

The **Zoho School of Technology Management System** helps streamline student and administrative management by providing a centralized system for handling records and operations.

It is designed with a user-friendly graphical interface using **Tkinter**, making it simple and accessible for educational institutions.

## ✨ Features

✅ Student Record Management  
✅ Add, Update, Delete Student Details  
✅ Search Student Information  
✅ User-Friendly GUI Interface  
✅ Database Integration  
✅ Organized Data Management  
✅ Fast and Efficient Record Access

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/gowthamunique08/zoho-school-of-technology-management-system.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd zoho-school-of-technology-management-system
```

### 3️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Project

```bash
python main.py
```
